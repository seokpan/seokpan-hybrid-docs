# Diagram font

SVG에는 각 그림에서 사용하는 글자만 추출한 Noto Sans CJK KR Regular 글꼴을 WOFF 형식으로 포함합니다. 텍스트와 도형은 편집할 수 있으며 외부 글꼴 서버를 호출하지 않습니다.

- 원본: [Noto CJK / Korean Regular](https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/Korean/NotoSansCJKkr-Regular.otf)

- License: [SIL Open Font License 1.1](NotoSansCJK-LICENSE.txt)

전체 OTF 원본은 저장소에 복제하지 않습니다. 재생성할 때 원본을 별도로 확보하고 설치합니다. 생성된 PNG에는 글꼴 설치가 필요하지 않습니다.
