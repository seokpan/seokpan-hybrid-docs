## 4. 검증 근거와 한계

- 00~04의 첨부→등록 파일→Manifest 바이트 수/SHA-256 및 Git blob 식별을 비교합니다. 동일성은 문서 내용의 정확성·Runtime PASS와 별개의 확인입니다.
- 이번 운영 지침은 제공된 `PROJECT_INSTRUCTIONS.md`, 2026-10-01 개정본입니다. SHA-256은 `67abd722fcef0776eb9f749bc493ebc894460b953a77290e8b5d0c989ef1f9d6`입니다. 지침은 Project Source에서 적용했으며 사용자 요청의 00~04 등록 범위에는 복사하지 않았습니다.
- 원문 Header 날짜는 00/01이 2026-09-30, 02/03/04가 2026-10-01 KST입니다. Manifest의 `source_basis_date`는 문서 묶음의 최신 결정 기준일이며 모든 원문의 개정일을 뜻하지 않습니다.
- 저장소의 현재 등록은 PR #3 작업 브랜치입니다. 검토 조회 시 PR은 open/draft/unmerged, main은 초기 README 상태였습니다. Source 원문 등록을 main 반영 완료로 표현하지 않습니다. 이후 등록 상태는 PR/Commit 이력에서 확인합니다.
- 상대 링크·그림 명세/파일명 수·문서 형식·공개할 비밀정보의 고위험 패턴을 확인했습니다. 패턴 검사에서 일치가 없다는 것은 모든 종류의 민감정보 부재를 보증하는 전수 보안 감사가 아닙니다.
- 외부 기술 사실/가격을 새로 확정하지 않았습니다. 지원 Version·가격·계정/Quota·실제 Source/Host는 구현 Gate입니다. 원문의 외부 근거 링크가 존재한다고 현재 내용/실환경을 다시 검증한 것은 아닙니다.
- 이미지가 아직 없으므로 SVG/PNG의 시각 검증은 미실행입니다. 설계 검토를 실제 HA/DR·무중단·성능/RTO/RPO·예산 충족 결과로 확대하지 않습니다.
