# 실행 범위·수신 방식

PC에서 준비한 고정 공개 도구 묶음을 기존 Controller jth 셸에 전달해 Python3.9+에서 실행했다. 긴 base64 명령·stdout/stderr 원문은 공개 증거에 넣지 않았다.

기존 운영 clone과 자격 파일을 읽거나 바꾸지 않고 home 아래 임시 폴더700·도구 파일600을 사용했다. 자식 시험 환경에서 AWS/TF/RHCS/KUBECONFIG 선택을 제외했고 기존 PyYAML이 있어 OCP 계산 시험도 실행됐다. 표준 라이브러리·기존 실행 환경만 사용했으며 설치하지 않았다. 실제 Linux 파일 검사와 두 시험의 판정 줄만 수신했다.

미실행: AWS/RHCS/Cluster API·Terraform/backend/State/Plan·git fetch/checkout·자격 파일 읽기/변경. 임시 사본 제거/부모 환경 보존은 helper 실행 완료 판정으로 수신했으며 별도의 현장 파일 전수 검사로 표시하지 않는다.
