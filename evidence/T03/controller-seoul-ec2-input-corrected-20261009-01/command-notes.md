# 명령·보호 범위

긴 PowerShell/클립보드/base64/셸 실행 줄과 오류 원문·보호 파일 내용은 게시하지 않는다. 원인 분류 및 오프라인 비교, 정규 임시 요청 파일 교정과 기존 Controller의 성공 판정만 연결한다.

기본 Caller/MFA·CPU Quota의 앞선 판정은 재사용했다. EC2 읽기는 DescribeInstances 및 DescribeCapacityReservations 두 목록의 첫/완료 페이지이며, 빈 결과로 DescribeInstanceTypes는 실행하지 않았다. 호출 상한12회와 실제 CLI 읽기2회를 구분한다.

STS/MFA/Token 반복·AssumeRole·Quota 증설·IAM/ROSA 변경·State/Output/Plan·Cloud 생성 없음. 파일700/600·각 요청 후 제거는 Source/보고 범위이며 보호 원본의 직접 재검사가 아니다.
