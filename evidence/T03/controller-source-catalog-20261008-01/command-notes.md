# 명령·범위

기존 Controller에서 `controller-readonly-preflight` 블록 실행 결과 수신. Git origin/status·fetch·HEAD/원격/Lock, Core version, Red Hat sts_credential_requests 목록과 기존 보관 정책 ID 비교. Git fetch는 참조 갱신만 수행. 인증·정책 목록의 성공 조회를 다시 실행한 결과로 표시하지 않음.

Git 출력 `LOCAL_AHEAD_REMOTE_BEHIND: 0 21`은 HEAD...origin/main의 좌/우 개수이며 로컬 ahead0/behind21로 해석. 실제 ARN·IAM 정책 내용/권한·A 수신 대조와 별도.

실제 실행 지연/서명·외부 정책 원본 진위 확인은 제공되지 않음. 보호 파일 내용/계정 프로필·Token/키·전체 State/Output/Plan은 수집/게시하지 않음.
