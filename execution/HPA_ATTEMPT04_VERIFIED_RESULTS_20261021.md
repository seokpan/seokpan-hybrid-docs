기록 순서에서 재구성한 최초 중단 기준 초과는 같은 phase의 첫 20건 중 응답 미확인 16건이다. 실제 보호 기준은 최근 전역 100기록 중 같은 phase가 20건 이상일 때 내용 검증 실패 비율이 5%를 넘는 경우다. 구간 전체 8%와 보호 기준 계산 창의 값은 다르다.

응답 미확인 기록에는 네트워크 예외의 상세 원인이 없어 서버 한계, 발생기 연결 한계, 네트워크 오류 중 무엇인지 확정할 수 없다. 따라서 200 VU를 최대 수용량으로 주장하지 않는다. AWS 비용 한도가 발생기를 직접 중단시킨 것은 아니며 비용 때문에 추가 재시험을 하지 않는 결정과 구분한다.
